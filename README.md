# 🚀 Automation Tasks API

Набор инструментов на базе FastAPI для управления личными скриптами и автоматизациями. Проект позволяет создавать, хранить, запускать и удалять задачи через REST API с сохранением данных в PostgreSQL.

## 🎯 Возможности

Проект предоставляет полноценный REST API для управления автоматизациями:

1. 📝 **Создание задач** (`POST /tasks/`)
   - Добавление новых скриптов и автоматизаций через API
   - Указание имени задачи и команды для запуска
   - Автоматическое присвоение уникального ID

2. 📋 **Просмотр задач** (`GET /tasks/`)
   - Получение списка всех сохранённых задач
   - Данные хранятся в PostgreSQL и не пропадают при перезагрузке сервера

3. 🔍 **Поиск задачи по ID** (`GET /tasks/{task_id}`)
   - Быстрый доступ к конкретной задаче по её идентификатору
   - Автоматическая обработка ошибок (404, если задача не найдена)

4. 🗑️ **Удаление задач** (`DELETE /tasks/{task_id}`)
   - Удаление ненужных задач из базы данных
   - Безопасная работа через сессии SQLModel

5. 📚 **Автодокументация** (Swagger UI)
   - Интерактивная документация API генерируется автоматически
   - Возможность тестировать эндпоинты прямо в браузере

## 🛠️ Технологии

- **Python 3.12+** — основной язык разработки
- **FastAPI** — современный высокопроизводительный веб-фреймворк
- **SQLModel** — ORM на базе Pydantic и SQLAlchemy для работы с БД
- **PostgreSQL** — надёжная реляционная база данных
- **Uvicorn** — ASGI-сервер для запуска приложения
- **python-dotenv** — безопасное хранение паролей и переменных окружения
